# Спецификация игры (черновик)

## Матч
- 4 игрока в комнате.
- 10 вопросов за матч (можно менять).
- На каждый вопрос даётся 15 секунд.
- За правильный ответ начисляем `15 − время ответа` (целое число, минимум 0).
- За неправильный ответ — 0 очков.

## Итог места в матче
- 1‑е место: +100 очков.
- 2‑е место: +50 очков.
- 3‑е место: −50 очков.
- 4‑е место: −100 очков.
- Итоговый общий счёт игрока не может быть ниже 0.

## Подсказки
- 50/50: 1 раз в день бесплатно.
- Повторные использования в одном матче: 10⭐, 20⭐, 40⭐, 80⭐ и т.д.
- На один вопрос 50/50 можно использовать только один раз.
- «Что выбирают чаще?» — показывает статистику ответов.
- Количество использований подсказок игроком не видно другим участникам.

## Слова и вопросы
- Ежедневно формируется пул из 50 слов.
- В матче вопросы берутся случайно из дневного пула.
- После накопления статистики показываем чаще слова, которые отвечают правильно реже.

## Данные для БД (минимум)
- Users: id, username, total_points, stars_balance.
- Matches: id, started_at, finished_at.
- MatchPlayers: match_id, user_id, score, place.
- Questions: id, word, options[], answer_index.
- QuestionStats: question_id, total, correct, picks[]
- DailyPool: date, question_ids[]
- HintUsage: user_id, date, daily_free_used, paid_uses_in_match.
