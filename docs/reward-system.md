# Система поощрения (идеи)

## Формат сезона
- Недельный сезон (понедельник–воскресенье по локальному времени).
- Итоги фиксируются автоматически в конце недели.
- Награды выдаются только при наличии минимум N сыгранных матчей за неделю (защита от случайных побед).

## Ранжирование
- Основа — сумма очков за неделю.
- Тай‑брейк: больше побед (1‑е места), затем выше точность ответов.

## Награды (пример)
- 1‑е место: «Золотой подарок» + крупный пакет звёзд.
- 2‑е место: «Серебряный подарок» + средний пакет звёзд.
- 3‑е место: «Бронзовый подарок» + небольшой пакет звёзд.
- 4–10 места: бейдж сезона + небольшое количество звёзд.

## Доставка наград через Telegram
- В БД создаём очередь `RewardQueue` с типом награды, количеством звёзд и статусом.
- После интеграции платежей/подарков Telegram бот или серверный воркер:
  - отправляет пользователю подарок,
  - списывает награду в очереди,
  - пишет лог в `RewardLog`.
- Если доставка не удалась — повтор через ретраи и уведомление админа.

## Анти‑чит
- Лимит матчей в день на очки сезона (например, учитываем только первые 30).
- Отсев подозрительных матчей (аномально быстрые ответы, 100% точность).
- Верификация устройства (device_id + telemetry) и rate‑limits.
